# GitCommands

### git init - инициализация Git в текущей директории

# git config

## git config user.name "username" - установка username (локально)
## git config user.email "email@mail.com" - установка email (локально)
## git config --global user.name "username" - установка username (глобально)
## git config --global user.email "email@mail.com" - установка email (глобально) 

--global - установка глобальной конфигурации
--list - просмотр текущей конфигурации Git конфигов

# git add . - добавление всех файлов в отслеживание

# git commit -m "name commit" - зафиксировать текущие изменения в коммите
-m - message 

# git log - показать логи изменений (вывести коммиты)
--oneline -

# git restore <file> - восстанавлиевает состояние последнего коммита. (восстанавливает до последнего коммита)
--staged <file> - удаляет из индексации

### git reset <commit> - возвращает состояние файлов к конкретному коммиту (Head)
--soft - файлы не меняются, не убирает индексацию
--mixed - файлы не меняются, убирает индексацию
--hard - файлы меняются, убирает индексацию
