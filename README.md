# Команды Git

### ⚙️ Настройка конфигурации (`git config`)
* **git config user.name "username"** — установка имени пользователя для **текущего** репозитория.
* **git config user.email "email@mail.com"** — установка email для **текущего** репозитория.
* **git config --global user.name "username"** — установка имени пользователя **глобально** для всех репозиториев.
* **git config --global user.email "email@mail.com"** — установка email **глобально** для всех репозиториев.
* **git config --list** — показать **все текущие настройки** Git.

---

### 📂 Инициализация и индексация (`init`, `add`, `commit`)
* **git init** — **инициализация** нового Git-репозитория в текущей директории.
* **git add .** — добавить **все измененные и новые файлы** в индекс (область подготовленных файлов).
* **git commit -m "сообщение"** — **зафиксировать** изменения, находящиеся в индексе, создав новый коммит.

---

### 📜 Просмотр истории (`log`, `reflog`)
* **git log** — показать историю коммитов текущей ветки.
  * `--oneline` — выводит каждый коммит в **одну строку** (короткий хэш и сообщение).
  * `--graph` — отображает историю коммитов в виде **текстового графа** ветвлений.
* **git reflog** — показать **журнал ссылок** (историю всех перемещений указателя `HEAD`). Помогает найти и восстановить удаленные коммиты или ветки.

---

### 🔄 Отмена изменений и откат (`restore`, `reset`, `revert`)
* **git restore <file>** — отменяет локальные изменения в файле, возвращая его к состоянию **последнего коммита**.
  * `--staged <file>` — убирает файл из индекса (unstage), но сохраняет изменения в самом коде.
* **git reset <commit>** — перемещает указатель текущей ветки на указанный коммит.
  * `--soft` — сбрасывает коммиты, но **сохраняет изменения** в файлах и оставляет их в индексе.
  * `--mixed` *(по умолчанию)* — сбрасывает коммиты и индекс, но **сохраняет изменения** в файлах как неиндексированные.
  * `--hard` — **полностью уничтожает** все изменения в рабочей директории и индексе, откатывая файлы к указанному коммиту.
* **git revert <commit>** — создает **новый коммит**, который вносит противоположные изменения, тем самым отменяя указанный коммит без изменения истории.

---

### 🧭 Навигация (`checkout`)
* **git checkout <commit>** — переключает файлы на состояние конкретного коммита (переводит Git в режим **detached HEAD**).
* **git checkout master** *(или имя другой ветки)* — возвращает указатель на основную ветку. Для переключения веток в современных версиях Git также используется команда `git switch`.
